# MWI 战斗模拟器使用教程

[English](user-guide.en.md)

项目内置了完整的中英文教程页面。启动项目后打开 `#/guide`，或点击顶部导航的“教程”。教程内容跟随软件顶部的全局语言设置。

## 推荐流程

1. 在主页点击“导入/导出”，安装主站导入脚本。
2. 保持游戏主站已登录，在模拟器点击“从主站导入”，直接导入当前单人角色。
3. 只有组队导入需要先在游戏主站逐个打开队友资料，供脚本缓存和补全队伍数据。
4. 在主页选择模拟目标、范围、难度和时长，运行一次战斗模拟。
5. 把当前方案设为基准，修改配装后加入队列并运行多轮比较。
6. 按需要使用刷图推荐、强化模拟和生活技能规划。

## 数据导入

导入窗口支持主站脚本、JSON 文本和本地文件。安装脚本后，单人角色可直接在模拟器点击“从主站导入”；只有组队导入需要预先在主站打开队友资料，并且只会使用已手动打开并缓存资料的队友。强化模拟和生活技能导入的数据只保留在当前页面会话，刷新后需要重新导入。

![导入导出窗口](../public/tutorial/import-data.png)

## 队列与多轮结果

先设为基准，再修改装备、技能或其他配置并加入队列。运行完成后，在多轮结果中查看综合评分、收益和经验变化、稳定性、成本与置信度，也可以导出 Excel。

> 队列目标装备买价依次使用官方精确 Ask、有效官方小时均价、历史归档最新有效 Ask。官方行情快照过期时才会刷新；新鲜快照没有精确卖单时会直接进入备用价格确认，避免重复请求。备用价格会显示来源和数据时间，新官方卖单仍优先。历史价不参与基准装备出售抵扣；基准无官方 bid/ask 时仍按 0 计算并警告。目标装备没有任何官方或历史价格时，可在加入队列前的确认弹窗中手动输入买入价；手动价格仅用于该队列项。买入价输入框仅接受大于 0 的整数，再用旁边的按钮选择 k/m/b 单位（如输入 5 并选择 m 表示 500 万）。
>
> 确认弹窗中选镜子方案时，“镜子成本（含基准件）”列的主数字是总成本：现金合成成本（垫子 + 镜子）+ 基准件按其出售价值计入，与多轮结果的“目标装备买入价”、队列页合计同一口径，括号内为直购对比价，下方小字标注构成明细（现金 + 基准件）。装备净成本 = 买入价 − 被替换装备出售价值，对镜子顶替行两侧同用确认时快照，因此净成本恒等于现金合成成本。基准件无市场价时主数字回落现金口径并附警告提示，且不再提示“出售抵扣按 0”警告。

## 专项工具

- 刷图推荐：按均衡、收益、经验、稳健、自定义权重或铁牛掉落模式扫描战斗目标。
- 强化模拟：比较保护策略、贤者之镜、分解价值、成本分位和预算成功率。
- 生活技能：按最低净成本/经验、均衡或速度优先规划六种技能的升级路线。
- 设置：调整队列评分、线程、采样轮次、市场价格口径和装备方案。

更详细的字段说明、操作顺序和常见问题请以项目内 `#/guide` 页面为准。教程截图位于 `public/tutorial/`，界面发生明显变化时应同步更新对应截图。
